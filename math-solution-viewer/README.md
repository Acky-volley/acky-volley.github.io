# MathArchive - 数学問題・模範解答アーカイブ Webサイト

数学の問題と詳しい模範解答を、教科書・学術論文クオリティの美しい数式（$\LaTeX$ / KaTeX）で整理・閲覧・演習できる個人用Webサイトです。

PCやスマートフォンのブラウザからいつでも確認でき、Web上の専用管理フォームから簡単に問題の追加・編集が可能です。
サーバー契約不要・完全無料で GitHub Pages や Vercel 等に公開できます。

---

## 🌟 主な機能

1. **美しい数式レンダリング（$\LaTeX$ / KaTeX & Markdown対応）**
   - `$x^2 + y^2 = 1$`（インライン数式）や `$$\int_0^1 f(x) dx$$`（ブロック数式）が高速・高精細に描画されます。
   - 途中式の揃え（`\begin{aligned}`）や行列（`\begin{pmatrix}`）、分数、極限、積分なども完璧に対応。
2. **ワンタップ・ワンクリックで模範解答を表示 / 隠す**
   - 普段は問題文だけを見て自力で考え、解き終わったら「模範解答を見る」ボタンを押して答え合わせができます。
   - 「ヒント」「別解・着眼点」も個別にアコーディオン表示可能。
3. **Web上の管理フォーム（追加・編集・プレビュー）**
   - タイトル、カテゴリ（数I・A、数II・B、数III・C、線形代数など）、難易度（★1〜★5）、タグを設定可能。
   - **数式クイック入力ツールバー付き**: 分数や積分、極限、ギリシャ文字をワンクリックで挿入。
   - 入力しながら右側のプレビュー画面で数式がその場で確認できるリアルタイムプレビュー機能。
4. **学習管理・検索機能**
   - **理解度チェック**: 問題ごとに「〇 マスター」「△ 要復習」「未着手」をワンクリックで記録。
   - **多機能フィルター**: カテゴリ、難易度、理解度ステータス、タグ、キーワードで瞬時に絞り込み。
   - **ランダム出題モード**: 「ランダム出題」ボタンで、登録された問題から今日解くべき1問をピックアップ。
5. **完全レスポンシブ & ダークモード対応**
   - スマートフォン（iPhone / Android）の片手操作でも見やすく押しやすいボタン設計。
   - 長い数式も横スクロールで崩れません。夜間学習に優しいダークモード切り替え付き。

## 🚀 すぐにローカル（PC）で動かす方法

### 方法 1: `start.bat` をダブルクリック（おすすめ）
フォルダ内の `start.bat` をダブルクリックすると、自動的にブラウザが立ち上がります。

### 方法 2: `index.html` を直接開く
`index.html` をChromeやEdgeなどのブラウザにドラッグ＆ドロップ、またはダブルクリックするだけでそのまま動作します（Node.jsや複雑なビルドは一切不要です）。

## 🌐 無料でWebに公開する手順（GitHub Pages）

このサイトは静的ファイル（HTML, CSS, JavaScript, JSON）のみで構築されているため、**GitHub Pagesを使って完全無料・サーバー代ゼロで世界中（スマホやタブレット）からアクセス可能**にできます。

### ステップ 1: GitHubで新しいリポジトリを作成
1. [GitHub](https://github.com/) にログインし、右上の「+」から **「New repository」** をクリックします。
2. リポジトリ名を入力します（例: `math-archive`）。
3. **「Public」**（公開）を選択し、**「Create repository」** を押します。

### ステップ 2: ファイルをアップロード
1. 作成されたリポジトリ画面で **「uploading an existing file」** をクリックします。
2. この `math-solution-viewer` フォルダ内のすべてのファイル：
   - `index.html`
   - `style.css`
   - `app.js`
   - `questions.json`
   - `README.md`
   をまとめてドラッグ＆ドロップします。
3. 画面下の **「Commit changes」** を押して保存します。

### ステップ 3: GitHub Pages を有効化
1. リポジトリの **「Settings」**（設定）タブを開きます。
2. 左メニューの **「Pages」** をクリックします。
3. **「Build and deployment」** の **「Branch」** で `main`（または `master`）を選択し、フォルダは `/ (root)` のまま **「Save」** を押します。
4. 1〜2分待つと、ページ上部にあなたのWebサイトのURLが表示されます！
   ```
   https://<あなたのGitHubユーザー名>.github.io/math-archive/
   ```
👉 このURLをスマホのブラウザで開いて「ホーム画面に追加」すれば、自作の数学問題集アプリとしていつでもどこでも利用できます！

## 📝 登録した問題をスマホや他の端末と同期する方法

ブラウザのフォームから新しく問題を追加・編集したあと、GitHubに反映させると全端末で最新の問題集が閲覧できるようになります。

1. PCのサイト上で **「問題を追加・管理」** → **「データ保存・GitHub公開用エクスポート」** タブを開きます。
2. **「questions.json をダウンロード」** ボタンを押します。
3. ダウンロードされた `questions.json` を、GitHubリポジトリの `questions.json` に上書きアップロード（Commit）します。
4. これだけで、スマホや他のPCからアクセスした時も、追加した新しい問題が最初から表示されるようになります！
